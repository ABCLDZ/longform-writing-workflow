# 可选视觉方案

只在用户要求配图建议、封面或视觉方案时使用。本文只产出方案，不依赖其他Skill、画风资产或生图服务。

先指出这张图要帮助读者理解哪条已成立信息。真实材料用于展示公开内容，图表用于有依据的数据关系，信息图用于必要结构，生成式场景仅作为说明或概念表达。没有独立帮助时可以不配图。

记录最小必要内容：位置、要说明的命题、视觉形式、对象与关系、来源或所据材料、不能暗示的内容、用户所需画幅和实际执行条件。优先已有且语义适合的资产，不用固定张数或风格决定信息预算。

图像不能把计划画成完工、可能关系画成确定因果，或让责任主体、范围与结果比正文更强。不得设计仿造网页冒充真实截图；拟用真实素材时记录实际来源和核实状态。

画风由用户及发布用途决定。用户只要方案时到此交付，不生成图片；明确要求实际制作时说明宿主可用能力、费用与相应范围，本包不把提示词或文件占位记成实际成图。
