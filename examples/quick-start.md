# 可复制的使用示例

以下机构、数字和事件均为虚构，仅用于演示任务输入，不是可作为真实报道引用的资料。观察点用于人工验收，不是模型成功率或已执行测试结果。

## 从材料直接写稿

```text
请使用已安装的“长风 / longform-writing-workflow”技能。
用下面的虚构材料写一篇300—450字的中文文章，读者是社区活动组织者。
给一个标题和完整正文，不用联网，不编造采访或参与者感受。

资料1：澄湾活动站在2026年9月举行4场周末活动，10月举行5场。
同口径报名记录显示，9月报名80人次、到场64人次；10月报名100人次、到场85人次。
资料2：10月新增短信提醒，同时调整了活动时间，并新增一名志愿者。
资料没有未使用短信提醒的对照组，也没有记录提醒成本。
资料3：活动站准备继续观察，尚未决定是否扩大短信提醒。
```

观察：直接交付正文；可说明到场率由80%变为85%，但不能把全部变化归因于短信；不把准备观察写成已决定推广。材料中的人次不应改为去重人数。

## 只精修一段

```text
请使用已安装的“长风 / longform-writing-workflow”技能。
只精修下面一段，让句子更顺。保留所有关键事实和判断强度，只给改稿。

根据供应商提供的记录，2026年8月，C线在两次由供应商参与调试的测试里，
平均处理时间相比2026年7月同口径测试缩短12%。截至8月31日，
还没有独立复测的记录，其他产线尚未部署。
```

观察：保留供应商归属、参与调试、两次、平均处理时间、比较口径、时点和部署范围；不能改为“独立证实效率提升12%”。如原稿已清晰，也可少改。

## 只判断标题

```text
请使用已安装的“长风 / longform-writing-workflow”技能。
只判断标题是否被正文支持；如不支持，给一个替代标题，不重写正文。

标题：短信提醒让社区活动到场率暴涨，全面推广已成定局
正文：澄湾活动站9月报名80人次、到场64人次，10月报名100人次、到场85人次。
10月新增短信提醒，也调整了活动时间，并新增一名志愿者。
没有对照组，站方准备继续观察，尚未决定推广。
```

观察：区分变化、因果和推广状态；替代标题可以明确写有依据的变化，无需把所有事实改成问句。

## 只做配图方案

```text
请使用已安装的“长风 / longform-writing-workflow”技能。
针对上一则虚构活动资料给一张信息图方案，只做方案，不生成图片。
让读者看出两个月的报名、到场人次和到场率，并保留不能据此确认因果的边界。
```

观察：图上主体、数字与比较口径一致；不能画成短信导致变化的确定因果图；方案不能被记为已生成的图像。
